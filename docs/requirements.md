# Requirements

## Purpose

The program is a small command-line fortune generator for introductory C
practice.

## Functional requirements

- Start from the command line without requiring user input.
- Print a short title and exactly one fortune.
- Choose the fortune from the program's built-in list.
- Exit successfully after printing the result.

## Build requirements

- Use standard C library facilities.
- Compile as a C11 program with a conventional C compiler.
