Project: Raspberry Pi Equipment Health Monitor
Status: C11 CPU/RAM/root-filesystem monitor with GPIO 17 and CSV logging;
        embedded CivetWeb HTTP server and JSON API added in Milestone 1.
Web: Static placeholder assets are served from web/; no finished dashboard yet.
API: GET /api/health and GET /api/metrics. Default bind is 127.0.0.1:8080.
Build: make requires libgpiod and CivetWeb development packages via pkg-config.
Tests: make test does not require either web server or physical GPIO libraries.
